<Description>
Storybook — главный каталог компонентов. Для каждого компонента добавляй состояния в
`*.stories.tsx`: это одновременно визуальная документация, примеры и проверяемые сценарии.
</Description>

## Быстрый старт

```bash
npm run storybook
```

Открой адрес из терминала, обычно `http://localhost:6006`. В Canvas можно менять props через
Controls, а во вкладке Docs — читать описание API и копировать примеры.

## Где что лежит

| Папка | Назначение |
| --- | --- |
| `src/components` | Переиспользуемые атомарные компоненты. |
| `src/tokens` | Цвета, отступы, радиусы и другие дизайн-токены. |
| `src/templates` | Готовые композиции и страницы из компонентов. |
| `*.stories.tsx` | Все поддерживаемые состояния и сценарии использования. |

## Правило добавления компонента

Создай папку `src/components/ComponentName` с четырьмя файлами:

```text
ComponentName.tsx
ComponentName.module.css
ComponentName.stories.tsx
index.ts
```

Перед тем как считать компонент готовым, покажи в story минимум default-состояние, крайние
состояния (disabled/loading/error), все variants и размеры. Если компоненты уже собираются в
реальный экран — создавай Template, а не добавляй продуктовую логику в примитив.
